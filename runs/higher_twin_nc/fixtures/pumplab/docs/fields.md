# Field reference

Data contract for `data/events.csv`, kept in sync with `schema.json`.

## `sample_id`

Field `sample_id` of type number. Unit: none.

## `flow_rate`

Field `flow_rate` of type number. Unit: L/min.

## `pressure`

Field `pressure` of type number. Unit: kPa.

## `temperature`

Field `temperature` of type number. Unit: C.

## `rpm`

Field `rpm` of type number. Unit: rpm.
