# Corpus index

A pinned corpus for the s04 denominator waterfall. Every stage is exercised on
purpose, so the published table has something to break against.

Every name here carries an `s04` prefix. That is not decoration: the corpus
lives inside the repository it documents, so plain names like `report.py` would
collide with real files and turn unrelated references elsewhere in the tree
ambiguous. A fixture must not corrupt the metric it exists to pin.
