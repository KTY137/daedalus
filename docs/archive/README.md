# Documentation archive

This directory retains historical and foreign-project material that is useful
for provenance but is not current Daedalus guidance. Archived files must not be
used as gate, architecture, benchmark, or operations authority.

The [Iron Plan](../IKARUS_ARIADNE_MASTER_PLAN.md) remains the sole semantic
authority. The [documentation index](../README.md) routes current readers, and
current executable work packets live in [`docs/work-packets/`](../work-packets/).

The July documents below were moved byte-identically. Their Git blob and
SHA-256 values were captured from the clean source path before the move.
Relative links inside an archived body are historical text and are not rewritten
to impersonate a current document.
