One product, two modes of attention

Four surfaces, one language. The Pass, the Cockpit and the Graphs are for operating: projected line art, high density, continuous motion, mono first. The Wiki is for reading, so density and motion are deliberately removed while palette, type and frame stay identical. That split is the system — a wiki that behaves like a HUD is unreadable, and a HUD that behaves like a wiki is useless. Click through all four.

The Pass. Every kitchen you have open, and who is at which station. A kitchen is a project; a station is a role; a worker is the model actually standing there. Service state reads from three metres — amber station means hands moving, and the ticket rail under each kitchen is the last six tasks, oldest left. This is the home screen, because the first question is never “what is the code like”, it is who is cooking and is anything burning.

The second graph: code as a representation of the data structure

The forest already holds files, imports and clone clusters. This layer adds the shape the code is about: types as nodes, fields as their children, and functions as edges between them — consumes for a parameter, produces for a return. A function stops being a box and becomes a transformation from one structure into another.

Invariant · load bearing

Type nodes never enter all_units. Measured: 176 dataclasses share a fingerprint by field count, so letting them reach the clone pass would publish them as renamed clones in the precise tier. See Invariants.

Where it plugs in

Extraction lives in structcore/parse.py because the file cache key mixes that module's own hash. Resolution is whole-repo and serial, like import resolution, and it uses a separate table — never graph.defs_by_file, which would turn field names into fabricated call edges.

Coverage reports itself: 97% of returns and 71% of parameters carry an annotation here, and every unresolved or ambiguous name is counted rather than guessed. Related: Knowledge space, Hub measurement.

What holds the four surfaces together, and what is deliberately not in here.

Projection, not glass

Panels are corner brackets and hairlines over a lit void — drawn, not printed. Filled frosted cards were the previous attempt and they read as generated.

Mono first, one display face

Everything measured is mono and tabular. Headlines only get the display face. No third family, and no grotesk body text — that is the uniform of every AI dashboard.

Light means live

Amber is hands-moving, lime is passed, oxide is failed or unread, ice is structure. Nothing glows unless something is actually happening.

Depth carries time

Spent attempts recede, the current one is sharp, the running one floats forward. In the graphs, Z is real: the projection rotates and depth-fades.

Reading mode is a mode

On the wiki, animation stops, measure widens to 66 characters, line-height opens to 1.78. Same palette, same frame — different job.

What got cut

Four-tile metric rows, nested rounded cards, permanent status legends, suggestion chips, raw JSON on the glass, and every shouted label that was decoration.
