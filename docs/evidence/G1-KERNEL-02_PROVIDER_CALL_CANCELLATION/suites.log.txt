4. Mutation B — the in-flight probe check removed
--------------------------------------------------
Mutant: the body of the wait loop in `run_cancellable` becomes `pass`, so
`cancelled()` is never consulted once the request is running.

    -k "in_flight_call_ends or parked_on_the_body"

    FAILED ...::test_an_in_flight_call_ends_when_the_probe_flips
    FAILED ...::test_a_call_parked_on_the_body_is_cancellable_too
    E   Failed: DID NOT RAISE ProviderCancelled
    2 failed, 14 deselected in 139.50s (0:02:19)

139.5 s for two tests whose server delay is 60 s each: without the probe check
the calls waited for the server, exactly as Momus's "hang or fall" requires.

Mutation B also found a real defect IN THE TESTS. The first mutant run failed
with

    AssertionError: assert 'in flight' in
        'cancelled before chat-completions opened a connection'

which is the wrong refusal: the `_FlipAfter` probes were constructed BEFORE the
`slow_server` fixture, so on a slow box the probe was already True at the
pre-flight check and the test would have passed without ever reaching an
in-flight call. Probes are now built after the server is up, and all three
cancellation tests assert which refusal fired.
