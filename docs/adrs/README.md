decision or preserve evidence, but they cannot override the
[Iron Plan](../IKARUS_ARIADNE_MASTER_PLAN.md) or declare a delivery gate closed.
The active derived status lives in the
[Fourfold v2 execution plan](../FOURFOLD_V2_EXECUTION_PLAN.md).
