daedalus · routing schematic

Do the cheap work for free. Spend Claude only where it matters.

A router in front of the agent crew. Every task is sized on two axes — can its bytes leave the machine, and how much damage can a bad edit do — then sent down the cheapest lane that's still safe. A local model drafts; a verify gate guards; Claude applies only what's left.

FIG.02 / DECIDE

Decision matrix

The whole policy, in five rules

Evaluated top-to-bottom; first match wins. This is select_provider() verbatim, not a summary. A free model can propose; it never merges a change on its own.

Free lanes are read-only proposers. Only a trusted, write-capable lane applies a diff.
#ConditionLaneRightsWhy
1 Role is not external_ok claude_cli write Hardware / safety domains never leave the trusted lane.
2 high change-risk write claude_cli write Irreversible / high-blast edits stay senior. (Review-only high-risk may still go free.)
3 Sensitive data ollama only low → write
mid → advisory		 Bytes stay on the machine. Never DeepSeek. Claude applies mid-risk.
4 Non-sensitive, key present deepseek advisory Cheapest external draft; Claude reviews + applies. Dormant without a key.
5 Non-sensitive, no key ollama low → write
mid → advisory		 Local bench does it free; low-risk it writes directly ($0 Claude).

Degrade rule: any chosen lane that's unreachable silently falls back to claude_cli — the run never fails for lack of a bench, it just costs tokens, and metrics raises the fallback-rate alarm if that happens too often.

FIG.04 / WIRE-IN

Where Claude sits

Adam owns trust. Ikarus runs the bench. Claude is the lane of last resort — and the one that merges.
senior lane · reviewer · router

Adam / Claude

The captain, not a worker. Decides trust and safety, then does the smallest amount of hands-on work.

  • Applies every advisory diff a free model proposes — the free lane drafts, Claude merges.
  • Owns all high-risk writes, sensitive-mid applies, and not-external-eligible roles.
  • Catches everything the gate rejects or Ikarus bounces back.
foreman · bounded local pool

Ikarus

Foreman of the contractor bench. Takes only work Adam has already cleared as low-risk; flies no higher.

  • Spawns local workers from a bounded pool (max_workers) in waves.
  • Enforces reduced rights — the write-guard refuses device / vendor / secret / high-risk paths.
  • Bounces anything that routes back to Claude — defense in depth, re-checks its own routing.

The only four things Claude pays for

Escalations — the bench was down or ineligible.
High-risk writes — HV, motion, state machine, architecture.
Sensitive applies — merging a mid-risk on-machine draft.
Verify-fail recovery — the rolled-back task lands here.

How it's driven: manual / Codex call today; an Ikarus batch for fan-out; and the durable path — a Claude Code PreToolUse hook that offloads eligible edits before Claude ever spends a token. See docs/INTEGRATION.md.

FIG.05 / GUARDS

Why it's safe to let a 7B model touch the repo

Four guards, all fail-closed
G1 Default-deny egress

Anything not explicitly allow-listed is treated as sensitive. Untrusted external APIs only ever see allow-listed bytes; the local lane and Claude are trusted and bypass it.

G2 Write-guard on paths

A baseline high-blast path floor (devices, controllers, state machines, secrets) is always unioned in. A project can extend it, never weaken it. Simulated backends stay writable; the real drivers don't.

G3 No policy → no write

A live write with no project policy loaded is refused outright and sent to Claude — otherwise the guards would run under an empty deny-list and safety code would be writable.

G4 Verify + rollback

Every bench write passes the report check and the project's own test suite before it's kept. Fail → the tree is reverted; unreverted remnants are reported, not swallowed.
